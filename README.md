# CakePHP Questions & Experiments

A learning repository for exploring CakePHP through practical questions, experiments, and solutions to common development problems.

## Goals

- Explore CakePHP concepts and features.
- Experiment with different implementations.
- Troubleshoot common errors.
- Document questions and practical solutions.
- Share knowledge to help other developers learn CakePHP.

## Setup

```bash
composer install

# Configure SECURITY_SALT in .env

docker-compose down
docker-compose build
docker-compose up -d
```

## Purpose

Learn CakePHP by experimenting, solving real-world problems, and sharing knowledge with other developers.
